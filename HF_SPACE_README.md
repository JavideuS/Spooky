# Spooky — Quantum Multi-Robot Path Planning

A hybrid quantum-classical framework for multi-robot path planning using QUBO
formulations. Try the interactive demo at `/demo` — pick a map and a solver
(D-Wave classical annealing, or PennyLane QAOA on CPU), add robots, and watch
the solved paths animate.

Source: [github.com/JavideuS/Spooky](https://github.com/JavideuS/Spooky) ·
Paper: [arXiv:2602.14799](https://arxiv.org/abs/2602.14799)
